# HackVenture 2026 - Smart Policing

Official static website for HackVenture 2026, a premier state-level smart policing hackathon organized by Mizoram Police and National Institute of Technology Mizoram.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Project Structure
- `index.html` - Main entry point
- `assets/css/` - Stylesheets
- `assets/js/` - JavaScript files
- `assets/images/` - Images and logos
- `assets/icons/` - Icon assets
- `documents/` - Public documents and brochures

## Local Development
1. Clone the repository.
2. Run a local web server (e.g., `python -m http.server 8000`).
3. Open `http://localhost:8000` in your browser.
